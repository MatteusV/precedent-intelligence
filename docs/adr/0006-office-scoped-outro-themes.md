# Outro themes belong to the Escritório

Product Temas are a short global list. When the Advogado picks Outro and types a name, that Tema lives on the Escritório: confirmation lists product recortes plus that office’s Outro names. Other offices never see “urgente.” Weak validation (minimum length, no clash with a product name) is enough because the blast radius is the tenant. A global Outro catalog would pollute the product; a non-persisted Outro would re-hit the API forever and never warm Cobertura.
